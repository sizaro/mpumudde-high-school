# Public homepage media

Place the approved Mpumudde High School homepage video here as:

`mpumudde-hero.mp4`

Recommended export:

- MP4 using H.264 video
- 1920 × 1080 or 1280 × 720
- 20–35 seconds
- Muted-friendly footage with no essential spoken information
- Compressed to approximately 8–15 MB

The hero also accepts a hosted video URL through `VITE_PUBLIC_HERO_VIDEO_URL`.
Until a school video is supplied, the poster image remains visible automatically.
